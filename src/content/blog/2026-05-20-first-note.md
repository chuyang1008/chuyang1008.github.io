这是这个博客的第一篇学习记录。与其等到准备好再开始，我决定先搭建一个可以持续写下去的地方：把遇到的问题、理解到的知识，以及完成项目后的复盘留下来。

## 这次我搭建了什么

这个站点使用 Astro 生成静态页面，并由 GitHub Pages 自动部署。文章放在 `src/content/blog` 目录中，写作时可以专注内容，不需要维护数据库或服务端。

一篇文章由 Markdown 与 Front Matter 组成。Front Matter 会定义标题、日期、摘要和分类；Astro 会在构建时校验这些字段，让文章自动出现在首页和文章列表中。

## 接下来会记录什么

- 前端开发中真正理解的新概念；
- 项目实践的过程、取舍与踩坑；
- 提升效率的工具和工作流；
- 值得回顾的学习方法。

希望每一篇文章都能在未来帮到自己，也能帮到恰好遇到类似问题的人。
